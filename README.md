# SODIUM GP

가로등이 켜지는 시간, 도시가 서킷이 되는 3D 웹 레이싱 게임. (Three.js + cannon-es, WebGL)

## 실행

- `index.html`을 더블클릭하면 바로 실행됩니다. (번들된 `dist/game.js` 사용, 차량 3D 모델 포함)
- 소스를 고쳤다면: `npm install` → `npm run build`

## 주요 기능

- 실차급 3D 모델 2종(Ferrari 458 Italia, 컨셉 GT) + 코드로 만든 차량 2종(바이에른 G8 쿠페: 직렬 6기통 트윈터보 FR 쿠페, 잉골 V10 플러스: 자연흡기 V10 미드십), 차체 색·휠 크기·림 색 커스텀. AI 차량은 매번 무작위
- 3바퀴 레이스, AI 5대, 아침·낮·황혼·밤 시간대. 흐르는 구름·태양/달·반짝이는 별이 있는 하늘, 시간대별 색 보정
- 코스마다 완전히 다른 환경
  - 다운타운: 초고층 빌딩 협곡, 네온사인(한글 간판 포함), 옥상 전광판, 유리 스카이브리지, 화분 가로수
  - 리버사이드: 코스를 가로지르는 강과 아치교 2곳, 박공지붕 주택가·저층 아파트, 공원 숲, 대관람차, 강 위를 오가는 보트, 먼 산
  - 하버: 바다와 안벽, 컨테이너 야적장, 갠트리 크레인, 정박·항해 중인 컨테이너선, 오일 탱크, 창고, 회전하는 등대 빛줄기
  - 블루 코스트: 해수욕장(파라솔·선베드·감시탑)과 파도 거품, 야자수, 언덕 지형과 풍력발전기, 드문드문한 호텔·카페·빌라, 잔교, 등대 곶과 갯바위, 떠다니는 요트
- 건물: 원통형·셋백·포디움+타워·ㄱ자 등 여러 형태 × 16종 외벽(오피스 유리, 커튼월, 핀, 콘크리트, 벽돌, 아파트, 상가, 창고, 주택, 호텔 등), 옥상 실외기·물탱크·안테나·헬리패드, 밤에는 창마다 무작위로 켜지는 불빛
- AI: 최소 곡률 레이싱 라인(아웃-인-아웃) + 코너 한계 속도·제동 거리 기반 속도 프로파일, 순수 추종 조향, 공간을 보고 고르는 추월, 스핀 후 3점 회전 회복. 난이도 4단계(쉬움·보통·어려움·프로), 드라이버 성향 8종
- 물리: 고정 스텝 + 렌더 보간, RaycastVehicle 서스펜션, 토크 곡선 기반 6단 기어박스(자동/수동), ABS처럼 잠기지 않는 브레이크, 엔진 브레이크, 속도 감응 조향, 자세 안정화(롤·피치 복원), 뒤집히면 부드럽게 바로 세우기, 복귀 시 잠깐 충돌 무시(겹침 방지)
- 벽 충돌: 코스 경계 기반 해석 — 살짝 스치면 미끄러지고 세게 박을 때만 튕김, 스파크·사운드 연동
- 최적화: 청크 단위 컬링, 모든 건물이 텍스처 배열 하나·머티리얼 하나를 공유(청크당 드로우콜 1번), 간판·광고는 아틀라스로 병합, 차량·정적 메쉬를 머티리얼별 병합, 안개 너머는 그리지 않음, 프레임이 느리면 해상도를 자동으로 낮추는 동적 해상도
- 스키드 마크, 타이어 연기, 블룸/그림자/반사(품질 4단계)
- 사운드: AudioWorklet로 기통별 폭발 펄스·배기관 공명을 합성하는 엔진음(V8·V10·V12·직6 터보), 오버런 팝·블로오프, 실내/실외 음색 차이, 주변 AI 차 엔진음(거리·좌우·도플러), 타이어 비명·노면·바람
- 카메라: 3인칭·3인칭(멀리)·보닛·1인칭. 가속/제동/코너의 관성으로 카메라와 머리가 움직이고, 속도에 따라 시야각이 넓어진다
- 시작 신호등, 랩 델타, 앞뒤 차 간격, 역주행 경고, 미니맵, 뒤보기, 게임패드, 모바일 멀티터치, 결과 화면 순위·베스트 랩 요약

## 조작

| 동작                    | 키보드                      | 모바일             |
| ----------------------- | --------------------------- | ------------------ |
| 가속 / 브레이크·후진    | ↑ W / ↓ S                   | 가속·브레이크 버튼 |
| 조향                    | ← → / A D, 화면 핸들 드래그 | 화면 핸들 드래그   |
| 핸드브레이크            | Space                       | 핸드 버튼          |
| 시점 전환 (4종)         | C                           | 시점 버튼          |
| 뒤보기                  | B 꾹 누르기                 | 뒤보기 버튼        |
| 수동 기어               | E / Q (설정에서 수동 선택)  | 기어 +/− 버튼      |
| 위치 복귀 / 일시정지    | R / Esc                     | 복귀 / Ⅱ 버튼      |

## 폴더 구조

```
index.html        진입 페이지 (메인 화면·HUD·모달 마크업)
css/              스타일
assets/           차량 3D 모델(glb, 웹용으로 경량화)
tools/            모델 경량화 스크립트
src/
  main.js         시작점 (모델 로드 → 게임 시작)
  game.js         레이스 진행, 카메라, 조명, 후처리, 렌더 루프
  config.js       차량·코스·AI·품질·시간대·설정 항목
  store.js        설정/커스텀 저장 (localStorage)
  world/          city.js(코스·테마별 환경 생성), buildings.js(건물 형태), facades.js(외벽 텍스처 배열·셰이더), nature.js(지형·바다·야자수·등대·풍차), sky.js(하늘)
  vehicle/        model.js(모델·조종석), procedural.js(코드로 만든 차체), car.js(물리·기어·자세 안정화), walls.js(벽 충돌), ai.js(레이싱 라인·AI)
  systems/        input.js, audio.js(엔진 합성), camera.js(카메라), fx.js(스키드·연기·스파크)
  util/           merge.js(정적 메쉬 병합)
  ui/             ui.js(메인·설정·가이드), hud.js
dist/game.js      빌드 결과물
```
